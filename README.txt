KEITAまなびクエスト・家族向けPWA版

公開方法：このフォルダーの index.html、manifest.webmanifest、sw.js、icons/ を同じ階層構造で HTTPS 対応ホスティングに配置してください。
例：GitHub Pages、Netlify、Cloudflare Pages。公開URLはまだ作成されていません。

iPhone/iPad：Safariで公開URLを開く→共有→ホーム画面に追加。

同じ端末の家族は、画面上部の「学習する人」で切り替えます。各人の履歴は別々に端末内(localStorage)へ保存します。ログイン機能や端末間同期はありません。

旧アプリの学習履歴：ブラウザ内に旧データがある場合のみ、「旧アプリの学習履歴を取り込む」で移行可能。ファイルとして開いた旧版の履歴は、公開URLの保存領域とは共有されない場合があります。その場合は旧アプリのJSONバックアップを新アプリでインポートしてください。

学習履歴を定期的にJSONで保存してください。ブラウザのデータ削除などで消える可能性があります。
